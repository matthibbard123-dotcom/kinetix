KINETIX WEBSITE
===============

This is a static, responsive website for the Kinetix gaming companion concept.

FILES
- index.html: website content
- styles.css: black and dark-green styling
- script.js: mobile navigation and footer year

PREVIEW
Open index.html in a modern browser.

PUBLISH ONLINE
1. Upload the contents of this folder to your web host's public website folder,
   or deploy the folder using a static hosting service such as GitHub Pages,
   Netlify, or Cloudflare Pages.
2. Connect your domain name if you have one.
3. When the Windows app is actually built and ready, upload the installer to
   your hosting/download provider and replace the disabled "Windows download
   coming soon" link in index.html with the real download URL.

IMPORTANT
The website currently advertises the Kinetix app as coming soon. It does not
contain a working app installer yet. Do not advertise an installer download
until the Windows application has been built, tested, and packaged.
Game integrations and automatic tracking depend on each game's supported data
access. This project is not affiliated with Roblox, Epic Games, Activision,
or Microsoft.
